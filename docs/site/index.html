Reference documentation. The guides are in the repository.

The services' API

  • API reference: every route of the four services.
  • openapi.json: the same, as OpenAPI 3.1, to generate clients from.

The Rust crates

  • edda-types: the models, the rules and the combat engine, shared by everyone.
  • edda-client: a typed client for the services, and Replica for optimistic UIs.
  • edda-auth: device keys, certificates, pairing and tokens.
  • edda-server: what every service shares.
  • auth-service, character-service, combat-service and monster-service: the services.
  • edda: the command line.
